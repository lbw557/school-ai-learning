任务 A：异常处理（20 分钟）

构造三类请求：

- 正常请求，返回 HTTP 200。
- 不存在的资源，返回 HTTP 404。
- 无法建立连接的地址，模拟连接失败。

要求单个请求失败不能导致其他请求结果丢失。

任务 B：限制并发数（15 分钟）

使用 `asyncio.Semaphore(3)`，让程序最多同时执行三个 HTTP 请求。

任务 C：汇总请求结果（20 分钟）

定义统一的数据结构，输出类似：

```
{
  "total": 3,
  "success": 2,
  "failed": 1,
  "results": [
    {
      "url": "https://example.com/a",
      "status": "success",
      "data": {}
    },
    {
      "url": "https://example.com/b",
      "status": "success",
      "data": {}
    },
    {
      "url": "https://example.com/c",
      "status": "failed",
      "error": "connection error"
    }
  ]
}
```

上面是目标结构示例，不代表真实请求结果。

将汇总结果保存到 `results.json`。
