任务 A：单个异步 HTTP 请求（15 分钟）

使用 `httpx.AsyncClient` 请求：

```
https://jsonplaceholder.typicode.com/users/1
```

解析返回的 JSON，提取用户 ID、姓名、邮箱。

任务 B：多个 HTTP 请求并发（25 分钟）

并发请求 `/users/1`、`/users/2`、`/users/3`，使用 `asyncio.gather()` 汇总返回数据。

要求三个请求共用一个 `AsyncClient`，不得每次请求都新建客户端。

任务 C：串行与并发对比（15 分钟）

将同样的三个请求分别串行和并发执行，测量耗时，记录网络请求并发后是否更快，并分析可能的原因。
